### Week 1 Objectives:

* Understand the overall AWS architecture and the main service groups.
* Create a safe AWS account for hands-on practice and become familiar with the console and CLI.

### Tasks to be carried out this week:
| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| Monday | - Learn the purpose of cloud computing and AWS global infrastructure.<br>- Study Regions, Availability Zones, edge locations, and the shared responsibility model. | 03/08/2026 | 03/08/2026 | <https://aws.amazon.com/getting-started/> |
| Tuesday | - Research the main AWS service groups: Compute, Storage, Networking, Database, Security, and Monitoring.<br>- Draw a high-level architecture showing how the groups work together. | 04/08/2026 | 04/08/2026 | <https://cloudjourney.awsstudygroup.com/> |
| Wednesday | - Create and secure an AWS Free Tier account.<br>- Enable MFA and review billing alerts, budgets, and account security settings. | 05/08/2026 | 05/08/2026 | <https://docs.aws.amazon.com/accounts/latest/reference/manage-acct-creating.html> |
| Thursday | - Study AWS Management Console and AWS CLI.<br>- Install the CLI and configure a practice profile with the default Region. | 06/08/2026 | 06/08/2026 | <https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-welcome.html> |
| Friday | - **Practice:** Verify the account and CLI configuration.<br>- Use the CLI to list Regions and inspect available services.<br>- Review notes and clean up any test resources. | 07/08/2026 | 07/08/2026 | <https://cloudjourney.awsstudygroup.com/> |

### Week 1 Achievements:

* Explained AWS global infrastructure, service categories, and the shared responsibility model.
* Created and secured an AWS Free Tier account with MFA and billing alerts.
* Installed and configured AWS CLI and used it to verify account settings and list Regions.
* Created a high-level AWS architecture diagram and documented the learning notes.
