### Week 2 Objectives:

* Understand EC2, S3, and IAM as core AWS services.
* Practice launching, securing, and using basic cloud resources.

### Tasks to be carried out this week:
| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| Monday | - Study EC2 concepts: AMI, instance types, EBS, key pairs, and security groups.<br>- Compare on-demand and free-tier usage. | 10/08/2026 | 10/08/2026 | <https://docs.aws.amazon.com/ec2/> |
| Tuesday | - Study S3 concepts: buckets, objects, storage classes, versioning, and lifecycle rules.<br>- Review basic S3 security principles. | 11/08/2026 | 11/08/2026 | <https://docs.aws.amazon.com/s3/> |
| Wednesday | - Study IAM users, groups, roles, policies, and least privilege.<br>- Learn why root credentials should not be used for daily work. | 12/08/2026 | 12/08/2026 | <https://docs.aws.amazon.com/iam/> |

| Friday | - **Practice:** Create an IAM user or role with limited permissions.<br>- Test EC2, S3, and IAM operations, then remove test resources. | 14/08/2026 | 14/08/2026 | <https://cloudjourney.awsstudygroup.com/> |

### Week 2 Achievements:

* Explained the purpose and common use cases of EC2, S3, and IAM.
* Launched and connected to an EC2 instance, uploaded an S3 object, and applied least-privilege permissions.
* Documented basic security and cost-control practices.
